# Plan 2: aplicación PWA (interfaz, guardado, PWA y E2E)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** una PWA instalable y jugable de punta a punta sobre el núcleo del plan 1: pantallas en React con estética liquid glass, guardado en IndexedDB, respaldo, cartas propias, modo sin conexión, CSP y pruebas E2E.

**Architecture:** `src/core` no cambia salvo la confirmación +18 (Task 1). Encima van tres capas: `src/store` (interfaz `UserStore` + IndexedDB, validación del estado), `src/app` (estado de usuario, partida y rutas por hash en contextos de React) y `src/ui` (pantallas y sistema visual con tokens CSS). Toda la lógica que se puede probar sin navegador es TypeScript puro con Vitest en Node; el navegador se prueba con Playwright.

**Tech Stack:** React 19.3.1, Vite 8.3.8, `@vitejs/plugin-react` 6.3.0, `vite-plugin-pwa` 2.0.0 (con `workbox-build` y `workbox-window` 7.4.1), `@fontsource-variable/bricolage-grotesque` y `@fontsource-variable/figtree` 5.3.0, `fake-indexeddb` 6.2.8, `@playwright/test` 1.65.0. Versiones consultadas con `npm view` el 2026-11-12. Sin ESLint (ver "Decisiones").

**Spec:** [`docs/superpowers/specs/2026-11-12-party-questions-pwa-design.md`](../specs/2026-11-12-party-questions-pwa-design.md). Plan anterior: [`2026-11-12-plan-1-core.md`](2026-11-12-plan-1-core.md) (ejecutado: 102 tests en verde).

## Decisiones tomadas al escribir este plan

1. **Liquid glass: sin librería, código propio (~150 líneas de CSS y un componente).**
   - Las librerías encontradas ([rt-liquid-glass](https://www.jsdelivr.com/package/npm/@rethink-js/rt-liquid-glass), [liquid-glass-react](https://github.com/rdev/liquid-glass-react), [GlassiFy](https://www.cssscript.com/liquid-glass-dynamic-displacement/), [liquid-glass-backdrop-react](https://www.pkgstats.com/pkg:liquid-glass-backdrop-react)) usan la misma técnica: `backdrop-filter: url(#filtro)` con `feDisplacementMap`. Esa técnica solo funciona en Chromium; Safari y Firefox reciben un desenfoque simple ([LogRocket](https://blog.logrocket.com/how-create-liquid-glass-effects-css-and-svg/), [bug de Firefox 1868479](https://bugzilla.mozilla.org/show_bug.cgi?id=1868479)). [V]
   - No agregan nada que no se pueda escribir aquí, son proyectos pequeños y recientes, y la spec pide pocas dependencias.
   - **Dos niveles:** nivel base con CSS puro (desenfoque, saturación, borde especular, sombra interior) que funciona en cualquier navegador; nivel de refracción con SVG, solo en Chromium y solo en la carta principal (Task 15).
   - **No verificado:** que Chrome en Android renderice `feDisplacementMap` dentro de `backdrop-filter`. Ninguna fuente lo confirma [S]. Por eso el nivel de refracción es la última tarea y exige probar en el teléfono. Si falla, se queda el nivel base, que ya es el diseño completo.
2. **Sin ESLint.** `typescript-eslint` 8.72.2 declara `typescript >=4.8.4 <6.1.0` y el proyecto usa TypeScript 7.0.2 [V]. En su lugar, un test de Vitest (`src/architecture.test.ts`, Task 4) recorre el código y falla si hay texto literal en el JSX, colores literales en `.tsx` o importaciones de `core` hacia otras capas. Es heurístico (regex, no un parser); su límite está documentado en el propio test.
3. **Rutas por hash, sin router.** Seis pantallas. El botón Atrás de Android funciona con `hashchange` y no se añade dependencia.
4. **Sin jsdom ni Testing Library.** Los componentes se prueban en el navegador (Playwright); la lógica vive en módulos puros.
5. **Nombre de la app: "Ronda" provisional.** Vive en `es.appName`, en `index.html` y en el manifest. Pregunta abierta 1 de la spec; cambiarlo son tres líneas.
6. **Cartas de arranque: 30 cartas mínimas** (`content/packs/starter.*.json`) para poder jugar y probar. El plan 3 las reemplaza por el pipeline real.
7. **Poda del historial: se difiere al plan 3.** La spec pide podar al cargar las entradas de cartas que ya no existen. Los ids del nivel extremo solo se conocen al cargar su chunk (que va aparte a propósito), así que podar al arrancar borraría historial válido. El plan 3 lo resuelve con la convención de ids. **Desviación consciente de la spec.**
8. **Confirmación +18 en el motor (I1 de la revisión final del plan 1).** `GameState.adultConfirmed` y la acción `CONFIRM_ADULT`.
9. **El historial se guarda después de cada carta mostrada,** desde un efecto en el contexto de partida.
10. **Quién juega esta noche** no se guarda (no está en `UserState`): es estado de la sesión, y por defecto juegan todos los jugadores guardados.

## Dirección visual (skill frontend-design)

**Sujeto:** un grupo de adultos alrededor de una mesa de noche, con un teléfono que pasa de mano en mano. Lo característico de ese mundo es el vidrio (vasos, botellas, hielo) y la luz tenue de una sala; por eso el cristal es el material y la luz cambia con el nivel.

**Lo memorable (la audacia se gasta aquí y solo aquí):** la atmósfera. El fondo es una aurora lenta cuyo matiz cambia con el nivel (se desliza de uno a otro con `@property`), y la carta es una losa de vidrio grueso con borde especular. Todo lo demás es quieto y disciplinado.

| Token | Valor |
|---|---|
| Base oscura | `oklch(0.2 0.06 <matiz del nivel>)` |
| Suave, "Atardecer" | matices 45 (albaricoque), 295 (lila), 195 (turquesa); base 285 |
| Picante, "Vino" | matices 8 (coral), 350 (fucsia), 55 (ámbar); base 345 |
| Extremo, "Brasa" | matices 27, 22, 60; base 25; más oscuro |
| Tema claro | las mismas auroras con luminosidad alta y texto oscuro tintado |
| Tipografía | **Bricolage Grotesque** (variable) para títulos, nombres y texto de carta; **Figtree** (variable) para la interfaz |
| Escala | `--step--1` 0.875rem, `--step-0` 1rem, `--step-1` 1.25rem, `--step-2` 1.6rem, `--step-3` clamp(1.7rem, 6.4vw, 2.5rem), `--step-4` clamp(2.8rem, 13vw, 5rem) |

**Layout:** móvil vertical, alineado a la izquierda, un solo escenario por pantalla.

```
┌────────────────────────┐
│ Verdad o reto      ( ≡ )│   barra: modo a la izquierda, menú a la derecha
│                        │
│  Turno de              │
│  Valentina             │   nombre enorme (step-4)
│                        │
│ ┌────────────────────┐ │
│ │  texto de la carta │ │   losa de vidrio grueso (step-3, línea corta)
│ └────────────────────┘ │
│                        │
│ [ Cumplió ] [ Se niega]│   acciones fijas abajo, zona del pulgar
└────────────────────────┘
```

**Revisión del plan contra los defectos típicos:**
- No usa fondo crema ni acento terracota; no hay fondo negro con un solo acento ácido; no hay tarjetas idénticas en rejilla (la pantalla de partida es un solo escenario).
- Sin etiquetas en mayúsculas sobre los títulos, sin numeración falsa, sin flechas en los botones, sin acentuar una sola palabra del titular.
- Los botones dicen la acción exacta ("Cumplió", "Se niega", "Empezar") y el mismo verbo se repite en todo el flujo.
- El movimiento no provocado es uno solo (la aurora, que se detiene con `prefers-reduced-motion`); el resto responde a una acción (pulsar, cambiar de nivel).
- Cambio hecho tras la revisión: la primera idea era un tema "neón" con una rejilla de tarjetas para elegir los modos; se sustituyó por chips en una lista porque los modos son una elección múltiple corta, no un catálogo.
- Calidad mínima: foco visible, contraste del texto sobre el vidrio (el vidrio lleva un tinte según el tema, no solo blanco translúcido), objetivos táctiles de 48 px, `prefers-reduced-motion`, margen seguro (`env(safe-area-inset-*)`).

```ts
import { describe, expect, it } from 'vitest';
import { deck, player, steppingClock } from '../testing/fixtures';
import { createGame, InvalidActionError, reduce, type EngineDeps, type GameConfig } from './engine';
import { createSeededRng } from './rng';

const players = [player('ana'), player('beto')];
const cards = [
  ...deck('t-soft', 'TRUTH', 'SOFT', 5),
  ...deck('d-soft', 'DARE', 'SOFT', 5),
  ...deck('t-ext', 'TRUTH', 'EXTREME', 5),
  ...deck('d-ext', 'DARE', 'EXTREME', 5),
];
const soft: GameConfig = { modes: ['TRUTH_OR_DARE'], level: 'SOFT', penalty: { kind: 'NONE' } };
const extreme: GameConfig = { ...soft, level: 'EXTREME' };

function deps(): EngineDeps {
  return { cards, rng: createSeededRng(7), clock: steppingClock() };
}

describe('+18 confirmation', () => {
  it('refuses to start an EXTREME game without confirmation', () => {
    expect(() => createGame(extreme, players, {}, deps())).toThrow('+18');
  });

  it('starts an EXTREME game when confirmed, and records it in the state', () => {
    const state = createGame(extreme, players, {}, deps(), true);
    expect(state.adultConfirmed).toBe(true);
    expect(state.phase.kind).toBe('AWAITING_CHOICE');
  });

  it('starts unconfirmed for lower levels', () => {
    expect(createGame(soft, players, {}, deps()).adultConfirmed).toBe(false);
  });

  it('refuses CHANGE_LEVEL to EXTREME until CONFIRM_ADULT is reduced', () => {
    const d = deps();
    const start = createGame(soft, players, {}, d);
    expect(() => reduce(start, { type: 'CHANGE_LEVEL', level: 'EXTREME' }, d)).toThrow(InvalidActionError);
    const confirmed = reduce(start, { type: 'CONFIRM_ADULT' }, d);
    const changed = reduce(confirmed, { type: 'CHANGE_LEVEL', level: 'EXTREME' }, d);
    expect(changed.config.level).toBe('EXTREME');
  });

  it('keeps the confirmation when the level goes back and forth', () => {
    const d = deps();
    const start = reduce(createGame(soft, players, {}, d), { type: 'CONFIRM_ADULT' }, d);
    const toExtreme = reduce(start, { type: 'CHANGE_LEVEL', level: 'EXTREME' }, d);
    const toSoft = reduce(toExtreme, { type: 'CHANGE_LEVEL', level: 'SOFT' }, d);
    expect(reduce(toSoft, { type: 'CHANGE_LEVEL', level: 'EXTREME' }, d).config.level).toBe('EXTREME');
  });
});
```

```ts
import { parsePack } from '../core/content/validator';

// Base packs travel in the main bundle; extreme packs are a separate chunk that
// only loads after the +18 confirmation (spec section 1).
const baseModules = import.meta.glob<unknown>('../../content/packs/*.json', { eager: true, import: 'default' });
const extremeModules = import.meta.glob<unknown>('../../content/packs/extreme/*.json', { import: 'default' });

const CORPUS_RULES = { bannedSoftWords: [], nearDuplicateThreshold: DEFAULT_NEAR_DUPLICATE_THRESHOLD } as const;

function parseEntries(entries: readonly (readonly [string, unknown])[]): Pack[] {
  return entries.map(([path, raw]) => parsePack(raw, path));
}

function requireLevel(packs: readonly Pack[], allowed: (level: Card['level']) => boolean, where: string): void {
  const wrong = packs.flatMap((pack) =>
    pack.cards.filter((card) => !allowed(card.level)).map((card) => `${pack.id}/${card.id} (${card.level})`),
  );
  if (wrong.length > 0) throw new Error(`${where} contain cards at a level they must not have: ${wrong.join(', ')}`);
}

const basePacks = parseEntries(Object.entries(baseModules));
requireLevel(basePacks, (level) => level !== 'EXTREME', 'Base packs');
assertCorpus(basePacks, CORPUS_RULES);

export function loadBaseCards(): Card[] {
  return basePacks.flatMap((pack) => [...pack.cards]);
}

export async function loadExtremeCards(): Promise<Card[]> {
  const entries = await Promise.all(
    Object.entries(extremeModules).map(async ([path, load]) => [path, await load()] as const),
  );
  const extremePacks = parseEntries(entries);
  requireLevel(extremePacks, (level) => level === 'EXTREME', 'Extreme packs');
  assertCorpus([...basePacks, ...extremePacks], CORPUS_RULES);
  return extremePacks.flatMap((pack) => [...pack.cards]);
}
```

```ts
export interface Finding {
  readonly line: number;
  readonly rule: string;
  readonly text: string;
}

/** Replaces comments with spaces (newlines kept) so line numbers survive. Heuristic: strings that contain "//" are not special-cased. */
function stripComments(source: string): string {
  const blank = (match: string): string => match.replace(/[^\n]/g, ' ');
  return source.replace(/\/\*[\s\S]*?\*\//g, blank).replace(/(^|[^:'"`])\/\/.*$/gm, (match, lead: string) => lead + blank(match.slice(lead.length)));
}

function lineOf(source: string, index: number): number {
  let line = 1;
  for (let i = 0; i < index; i += 1) if (source[i] === '\n') line += 1;
  return line;
}

function collect(source: string, rule: string, pattern: RegExp): Finding[] {
  const text = stripComments(source);
  const findings: Finding[] = [];
  for (const match of text.matchAll(pattern)) {
    findings.push({ line: lineOf(text, match.index), rule, text: match[0].trim() });
  }
  return findings;
}

/**
 * Finds user-visible literal text in JSX: text nodes, string attributes read by
 * assistive tech, and `{'literal'}` expressions. It is a regex heuristic, not a
 * parser: text containing ( ) ; = is not detected, which keeps `useState<string>(x)`
 * and arrow functions from producing false positives.
 */
export function findJsxLiterals(source: string): Finding[] {
  return [
    ...collect(source, 'jsx-text', />([^<>{}=;()]*\p{L}[^<>{}=;()]*)</gu),
    ...collect(source, 'jsx-attribute', /\b(?:aria-label|aria-description|title|placeholder|alt)\s*=\s*"[^"]*\p{L}[^"]*"/gu),
    ...collect(source, 'jsx-expression', />\s*\{\s*(['"`])[^'"`]*\p{L}[^'"`]*\1\s*\}/gu),
  ];
}

/** Finds literal colors: the only source of color is the token file. */
export function findColorLiterals(source: string): Finding[] {
  return collect(source, 'color', /#[0-9a-fA-F]{3,8}\b|\b(?:rgba?|hsla?|oklch|oklab|lch|lab|color)\(/g);
}
```

```ts
function listFiles(dir: string, extension: RegExp): string[] {
  return readdirSync(dir, { withFileTypes: true }).flatMap((entry) => {
    const full = join(dir, entry.name);
    if (entry.isDirectory()) return listFiles(full, extension);
    return extension.test(entry.name) ? [full] : [];
  });
}

const IMPORT_PATTERN = /(?:import|export)\s[^'"]*?from\s*['"]([^'"]+)['"]|import\(\s*['"]([^'"]+)['"]\s*\)/g;

describe('architecture', () => {

    const coreDir = join(SRC, 'core') + sep;
    const offenders: string[] = [];
    for (const file of listFiles(join(SRC, 'core'), /\.ts$/)) {
      const source = readFileSync(file, 'utf8');
      for (const match of source.matchAll(IMPORT_PATTERN)) {
        const specifier = match[1] ?? match[2];
        if (specifier === undefined) continue;
        if (specifier.startsWith('.')) {
          if (!(resolve(dirname(file), specifier) + sep).startsWith(coreDir)) offenders.push(`${file}: ${specifier}`);
        } else if (specifier !== 'vitest' && !specifier.startsWith('vitest/')) {
          offenders.push(`${file}: ${specifier}`);
        }
      }
    }
    expect(offenders).toEqual([]);

    const offenders = listFiles(SRC, /\.tsx$/).flatMap((file) =>

      } else if (typeof value === 'object' && value !== null) {
```

```ts
import { GAME_MODES, LEVELS, type Card, type GameMode } from '../core/content/types';
import { checkCard } from '../core/content/validator';
import type { GameConfig, Penalty } from '../core/game/engine';
import { ATTRACTIONS, GENDERS, type Attraction, type Gender, type Player } from '../core/game/player';

export const SCHEMA_VERSION = 1;
export const CUSTOM_ID_PREFIX = 'custom-';
export const THEMES = ['SYSTEM', 'LIGHT', 'DARK'] as const;
export type Theme = (typeof THEMES)[number];

export interface UserSettings {
  readonly theme: Theme;
  readonly lastConfig?: GameConfig;
}

export interface UserState {
  readonly schemaVersion: number;
  readonly players: readonly Player[];
  /** cardId -> last time shown (epoch ms). */
  readonly history: Readonly<Record<string, number>>;
  readonly customCards: readonly Card[];
  readonly settings: UserSettings;
}

/** Carries the raw stored value so the error screen can export it untouched. */
export class UserStateError extends Error {
  readonly raw: unknown;

  constructor(message: string, raw: unknown) {
    super(message);
    this.name = 'UserStateError';
    this.raw = raw;
  }
}

export function emptyUserState(): UserState {
  return { schemaVersion: SCHEMA_VERSION, players: [], history: {}, customCards: [], settings: { theme: 'SYSTEM' } };
}

const TOP_LEVEL_FIELDS = new Set(['schemaVersion', 'players', 'history', 'customCards', 'settings']);

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value);
}

function oneOf<T extends string>(list: readonly T[], value: unknown): value is T {
  return typeof value === 'string' && (list as readonly string[]).includes(value);
}

function parsePlayers(raw: unknown, problems: string[]): Player[] {
  if (!Array.isArray(raw)) {
    problems.push(`players must be an array, got ${JSON.stringify(raw)}`);
    return [];
  }
  const players: Player[] = [];
  const ids = new Set<string>();
  const names = new Set<string>();
  raw.forEach((item: unknown, index: number) => {
    const where = `players[${index}]`;
    if (!isRecord(item)) {
      problems.push(`${where} must be an object`);
      return;
    }
    const { id, name, gender, attractedTo } = item;
    let ok = true;
    if (typeof id !== 'string' || id.length === 0) {
      problems.push(`${where}.id must be a non-empty string, got ${JSON.stringify(id)}`);
      ok = false;
    } else if (ids.has(id)) {
      problems.push(`${where}.id "${id}" is duplicated`);
      ok = false;
    }
    if (typeof name !== 'string' || name.trim().length === 0) {
      problems.push(`${where}.name must be a non-empty string, got ${JSON.stringify(name)}`);
      ok = false;
    } else if (names.has(name.trim().toLowerCase())) {
      problems.push(`${where}.name "${name}" is duplicated (case-insensitive)`);
      ok = false;
    }
    if (!oneOf(GENDERS, gender)) {
      problems.push(`${where}.gender must be one of ${GENDERS.join(', ')}, got ${JSON.stringify(gender)}`);
      ok = false;
    }
    if (!oneOf(ATTRACTIONS, attractedTo)) {
      problems.push(`${where}.attractedTo must be one of ${ATTRACTIONS.join(', ')}, got ${JSON.stringify(attractedTo)}`);
      ok = false;
    }
    if (ok) {
      ids.add(id as string);
      names.add((name as string).trim().toLowerCase());
      players.push({
        id: id as string,
        name: (name as string).trim(),
        gender: gender as Gender,
        attractedTo: attractedTo as Attraction,
      });
    }
  });
  return players;
}

function parseHistory(raw: unknown, problems: string[]): Record<string, number> {
  if (!isRecord(raw)) {
    problems.push(`history must be an object, got ${JSON.stringify(raw)}`);
    return {};
  }
  const history: Record<string, number> = {};
  for (const [cardId, seen] of Object.entries(raw)) {
    if (typeof seen !== 'number' || !Number.isFinite(seen) || seen < 0) {
      problems.push(`history["${cardId}"] must be a non-negative number, got ${JSON.stringify(seen)}`);
    } else {
      history[cardId] = seen;
    }
  }
  return history;
}

function parseCustomCards(raw: unknown, problems: string[]): Card[] {
  if (!Array.isArray(raw)) {
    problems.push(`customCards must be an array, got ${JSON.stringify(raw)}`);
    return [];
  }
  const cards: Card[] = [];
  const ids = new Set<string>();
  raw.forEach((item: unknown, index: number) => {
    const check = checkCard(item, `customCards[${index}]`);
    for (const problem of check.problems) problems.push(`${check.label}: ${problem}`);
    if (check.card === null) return;
    if (!check.card.id.startsWith(CUSTOM_ID_PREFIX)) {
      problems.push(`${check.label}: custom card ids must start with "${CUSTOM_ID_PREFIX}"`);
    } else if (ids.has(check.card.id)) {
      problems.push(`${check.label}: id is duplicated`);
    } else {
      ids.add(check.card.id);
      cards.push(check.card);
    }
  });
  return cards;
}

function parsePenalty(raw: unknown, problems: string[]): Penalty | null {
  const where = 'settings.lastConfig.penalty';
  if (!isRecord(raw)) {
    problems.push(`${where} must be an object, got ${JSON.stringify(raw)}`);
    return null;
  }
  switch (raw.kind) {
    case 'NONE':
      return { kind: 'NONE' };
    case 'GARMENT':
      return { kind: 'GARMENT' };
    case 'DRINKS': {
      const count = raw.count;
      if (count === 1 || count === 2 || count === 3 || count === 4 || count === 5) return { kind: 'DRINKS', count };
      problems.push(`${where}.count must be 1 to 5, got ${JSON.stringify(count)}`);
      return null;
    }
    default:
      problems.push(`${where}.kind must be NONE, GARMENT or DRINKS, got ${JSON.stringify(raw.kind)}`);
      return null;
  }
}

function parseConfig(raw: unknown, problems: string[]): GameConfig | null {
  const where = 'settings.lastConfig';
  if (!isRecord(raw)) {
    problems.push(`${where} must be an object, got ${JSON.stringify(raw)}`);
    return null;
  }
  const { modes, level } = raw;
  let parsedModes: GameMode[] = [];
  if (
    !Array.isArray(modes) ||
    modes.length === 0 ||
    !modes.every((mode: unknown): mode is GameMode => oneOf(GAME_MODES, mode)) ||
    new Set(modes).size !== modes.length
  ) {
    problems.push(`${where}.modes must be a non-empty list of unique modes from ${GAME_MODES.join(', ')}, got ${JSON.stringify(modes)}`);
  } else {
    parsedModes = modes;
  }
  if (!oneOf(LEVELS, level)) problems.push(`${where}.level must be one of ${LEVELS.join(', ')}, got ${JSON.stringify(level)}`);
  const penalty = parsePenalty(raw.penalty, problems);
  if (penalty === null || !oneOf(LEVELS, level) || parsedModes.length === 0) return null;
  return { modes: parsedModes, level, penalty };
}

function parseSettings(raw: unknown, problems: string[]): UserSettings {
  if (!isRecord(raw)) {
    problems.push(`settings must be an object, got ${JSON.stringify(raw)}`);
    return { theme: 'SYSTEM' };
  }
  let theme: Theme = 'SYSTEM';
  if (oneOf(THEMES, raw.theme)) theme = raw.theme;
  else problems.push(`settings.theme must be one of ${THEMES.join(', ')}, got ${JSON.stringify(raw.theme)}`);
  const lastConfig = raw.lastConfig === undefined ? null : parseConfig(raw.lastConfig, problems);
  return lastConfig === null ? { theme } : { theme, lastConfig };
}

/** Validates a raw stored value. Throws UserStateError listing every problem; never repairs anything. */
export function parseUserState(raw: unknown, source: string): UserState {
  if (!isRecord(raw)) throw new UserStateError(`${source}: stored state must be a JSON object, got ${JSON.stringify(raw)}`, raw);
  if (raw.schemaVersion !== SCHEMA_VERSION) {
    throw new UserStateError(
      `${source}: unsupported schemaVersion ${JSON.stringify(raw.schemaVersion)}, this app reads ${SCHEMA_VERSION}`,
      raw,
    );
  }
  const problems: string[] = [];
  for (const key of Object.keys(raw)) {
    if (!TOP_LEVEL_FIELDS.has(key)) problems.push(`unknown field "${key}"`);
  }
  const state: UserState = {
    schemaVersion: SCHEMA_VERSION,
    players: parsePlayers(raw.players, problems),
    history: parseHistory(raw.history, problems),
    customCards: parseCustomCards(raw.customCards, problems),
    settings: parseSettings(raw.settings, problems),
  };
  if (problems.length > 0) {
    throw new UserStateError(`${source}: invalid user state:\n- ${problems.join('\n- ')}`, raw);
  }
  return state;
}
```

```ts
import type { UserStore } from './userStore';

export const DEFAULT_DB_NAME = 'party-questions';
export const STORE_NAME = 'state';
export const RECORD_KEY = 'user-state';

function describe(error: DOMException | null): string {
  return error === null ? 'unknown error' : `${error.name}: ${error.message}`;
}

/** The whole UserState lives in one record, so every save is one atomic transaction. */
export class IndexedDbStore implements UserStore {
  private connection: Promise<IDBDatabase> | null = null;

  constructor(private readonly dbName: string = DEFAULT_DB_NAME) {}

  private open(): Promise<IDBDatabase> {
    if (this.connection === null) {
      this.connection = new Promise<IDBDatabase>((resolve, reject) => {
        const request = indexedDB.open(this.dbName, 1);
        request.onupgradeneeded = () => request.result.createObjectStore(STORE_NAME);
        request.onsuccess = () => resolve(request.result);
        request.onerror = () => reject(new Error(`Cannot open IndexedDB "${this.dbName}": ${describe(request.error)}`));
        request.onblocked = () => reject(new Error(`IndexedDB "${this.dbName}" is blocked by another open connection`));
      }).catch((error: unknown) => {
        this.connection = null;
        throw error;
      });
    }
    return this.connection;
  }

  async load(): Promise<UserState> {
    const db = await this.open();
    const raw = await new Promise<unknown>((resolve, reject) => {
      const request = db.transaction(STORE_NAME, 'readonly').objectStore(STORE_NAME).get(RECORD_KEY);
      request.onsuccess = () => resolve(request.result);
      request.onerror = () => reject(new Error(`Reading "${this.dbName}/${RECORD_KEY}" failed: ${describe(request.error)}`));
    });
    if (raw === undefined) return emptyUserState();
    return parseUserState(raw, `IndexedDB ${this.dbName}/${RECORD_KEY}`);
  }

  async save(state: UserState): Promise<void> {
    const db = await this.open();
    await new Promise<void>((resolve, reject) => {
      const tx = db.transaction(STORE_NAME, 'readwrite');
      tx.oncomplete = () => resolve();
      tx.onerror = () => reject(new Error(`Saving user state to "${this.dbName}" failed: ${describe(tx.error)}`));
      tx.onabort = () => reject(new Error(`Saving user state to "${this.dbName}" was aborted: ${describe(tx.error)}`));
      tx.objectStore(STORE_NAME).put(state, RECORD_KEY);
    });
  }
}
```

```ts
import type { Card } from '../core/content/types';
import { parsePack } from '../core/content/validator';
import { CUSTOM_ID_PREFIX, parseUserState, type UserState } from './userState';

export const BACKUP_FORMAT = 'party-questions-backup';
export const CUSTOM_PACK_ID = 'custom-cards';

function parseJson(text: string, source: string): unknown {
  try {
    return JSON.parse(text);
  } catch (error) {
    throw new Error(`${source} is not valid JSON: ${error instanceof Error ? error.message : String(error)}`);
  }
}

export function serializeBackup(state: UserState, exportedAt: number): string {
  return JSON.stringify({ format: BACKUP_FORMAT, exportedAt, state }, null, 2);
}

/** Throws with the reason when the text is not a valid backup. Never partially applies. */
export function parseBackup(text: string): UserState {
  const raw = parseJson(text, 'Backup file');
  if (typeof raw !== 'object' || raw === null || (raw as { format?: unknown }).format !== BACKUP_FORMAT) {
    throw new Error(`Backup file has format ${JSON.stringify((raw as { format?: unknown } | null)?.format)}, expected "${BACKUP_FORMAT}"`);
  }
  return parseUserState((raw as { state?: unknown }).state, 'backup file');
}

export function serializeCustomPack(cards: readonly Card[]): string {
  return JSON.stringify({ id: CUSTOM_PACK_ID, version: 1, lang: 'es', cards }, null, 2);
}

export interface ImportResult {
  readonly state: UserState;
  readonly added: number;
  readonly skipped: number;
}

/** Validates the whole pack first; one invalid or conflicting card rejects the file. */
export function importCustomPack(state: UserState, text: string, sourceName: string): ImportResult {
  const pack = parsePack(parseJson(text, sourceName), sourceName);
  const notCustom = pack.cards.filter((card) => !card.id.startsWith(CUSTOM_ID_PREFIX));
  if (notCustom.length > 0) {
    throw new Error(`${sourceName}: imported card ids must start with "${CUSTOM_ID_PREFIX}": ${notCustom.map((c) => c.id).join(', ')}`);
  }
  const existing = new Map(state.customCards.map((card) => [card.id, card]));
  const conflicts = pack.cards.filter((card) => {
    const current = existing.get(card.id);
    return current !== undefined && current.text !== card.text;
  });
  if (conflicts.length > 0) {
    throw new Error(`${sourceName}: cards already exist with different text: ${conflicts.map((c) => c.id).join(', ')}`);
  }
  const fresh = pack.cards.filter((card) => !existing.has(card.id));
  return {
    state: { ...state, customCards: [...state.customCards, ...fresh] },
    added: fresh.length,
    skipped: pack.cards.length - fresh.length,
  };
}
```

```ts
/** Call from a user gesture. Chrome decides by heuristics, so DENIED is a normal answer (spec section 3). */
export async function requestPersistence(storage: StorageManager | undefined): Promise<PersistenceResult> {
```

```ts
import type { Theme } from '../../store/userState';

export function effectiveTheme(choice: Theme, prefersDark: boolean): 'light' | 'dark' {
  if (choice === 'LIGHT') return 'light';
  if (choice === 'DARK') return 'dark';
  return prefersDark ? 'dark' : 'light';
}
```

`src/ui/theme/useAppearance.ts`:

```ts
import { useEffect } from 'react';
import type { Level } from '../../core/content/types';
import type { Theme } from '../../store/userState';
import { effectiveTheme } from './applyTheme';

/** Sets data-theme and data-level on <html>; CSS does the rest. */
export function useAppearance(theme: Theme, level: Level): void {
  useEffect(() => {
    const query = window.matchMedia('(prefers-color-scheme: dark)');
    const apply = (): void => {
      document.documentElement.dataset.theme = effectiveTheme(theme, query.matches);
    };
    apply();
    query.addEventListener('change', apply);
    return () => query.removeEventListener('change', apply);
  }, [theme]);

  useEffect(() => {
    document.documentElement.dataset.level = level;
  }, [level]);
}
```

```tsx
import { useEffect, useId, useRef, type ReactNode } from 'react';

interface DialogProps {
  readonly title: string;
  readonly onClose: () => void;
  readonly testId?: string;
  readonly children: ReactNode;
}

/** Native <dialog>: focus trap and Escape come from the browser. */
export function Dialog({ title, onClose, testId, children }: DialogProps) {
  const ref = useRef<HTMLDialogElement>(null);
  const titleId = useId();

  useEffect(() => {
    const element = ref.current;
    if (element === null) throw new Error('Dialog element is missing');
    if (!element.open) element.showModal();
  }, []);

  return (
    <dialog ref={ref} className="sheet glass glass--thick" aria-labelledby={titleId} onClose={onClose} data-testid={testId}>
      <div className="stack">
        <h2 id={titleId}>{title}</h2>
        {children}
      </div>
    </dialog>
  );
}
```

```ts
export const ROUTE_NAMES = ['home', 'players', 'setup', 'play', 'cards', 'settings'] as const;
export type RouteName = (typeof ROUTE_NAMES)[number];

export type Route =
  | { readonly name: RouteName }
  | { readonly name: 'kit' }
  | { readonly name: 'unknown'; readonly hash: string };

export function parseRoute(hash: string, devMode: boolean): Route {
  const path = hash.replace(/^#\/?/, '');
  if (path === '') return { name: 'home' };
  if ((ROUTE_NAMES as readonly string[]).includes(path)) return { name: path as RouteName };
  if (path === 'kit' && devMode) return { name: 'kit' };
  return { name: 'unknown', hash };
}

export function routeHash(name: RouteName): string {
  return name === 'home' ? '#/' : `#/${name}`;
}

export function navigate(name: RouteName): void {
  window.location.hash = routeHash(name);
}
```

```tsx
import { createContext, useCallback, useContext, useEffect, useMemo, useRef, useState, type ReactNode } from 'react';
import { es } from '../i18n/es';
import type { UserState } from '../store/userState';
import type { UserStore } from '../store/userStore';
import { LoadError } from '../ui/screens/LoadError';

interface UserStateApi {
  readonly state: UserState;
  /** Set when the last save failed. Shown to the user; never swallowed. */
  readonly saveError: string | null;
  update(change: (current: UserState) => UserState): void;
}

type Loaded = { kind: 'loading' } | { kind: 'error'; error: unknown } | { kind: 'ready'; state: UserState };

const Context = createContext<UserStateApi | null>(null);

export function useUserState(): UserStateApi {
  const value = useContext(Context);
  if (value === null) throw new Error('useUserState must be used inside UserStateProvider');
  return value;
}

export function UserStateProvider({ store, children }: { store: UserStore; children: ReactNode }) {
  const [loaded, setLoaded] = useState<Loaded>({ kind: 'loading' });
  const [saveError, setSaveError] = useState<string | null>(null);
  const latest = useRef<UserState | null>(null);

  useEffect(() => {
    let cancelled = false;
    store.load().then(
      (state) => {
        if (cancelled) return;
        latest.current = state;
        setLoaded({ kind: 'ready', state });
      },
      (error: unknown) => {
        if (!cancelled) setLoaded({ kind: 'error', error });
      },
    );
    return () => {
      cancelled = true;
    };
  }, [store]);

  const update = useCallback(
    (change: (current: UserState) => UserState): void => {
      if (latest.current === null) throw new Error('Cannot update the user state before it is loaded');
      const next = change(latest.current);
      latest.current = next;
      setLoaded({ kind: 'ready', state: next });
      store.save(next).then(
        () => setSaveError(null),
        (error: unknown) => setSaveError(es.errors.saveFailed(error instanceof Error ? error.message : String(error))),
      );
    },
    [store],
  );

  const readyState = loaded.kind === 'ready' ? loaded.state : null;
  const api = useMemo<UserStateApi | null>(
    () => (readyState === null ? null : { state: readyState, saveError, update }),
    [readyState, saveError, update],
  );

  if (loaded.kind === 'loading') {
    return (
      <main className="screen">
        <p>{es.common.loading}</p>
      </main>
    );
  }
  if (loaded.kind === 'error') return <LoadError error={loaded.error} />;
  return <Context.Provider value={api}>{children}</Context.Provider>;
}
```

```ts
import type { Attraction, Gender, Player } from '../../core/game/player';

export interface PlayerDraft {
  readonly name: string;
  readonly gender: Gender;
  readonly attractedTo: Attraction;
}

export const EMPTY_DRAFT: PlayerDraft = { name: '', gender: 'UNDISCLOSED', attractedTo: 'UNDISCLOSED' };

export type PlayerFormError = { readonly kind: 'NAME_EMPTY' } | { readonly kind: 'NAME_TAKEN'; readonly name: string };

export function validatePlayerDraft(
  draft: PlayerDraft,
  players: readonly Player[],
  editingId: string | null,
): PlayerFormError | null {
  const name = draft.name.trim();
  if (name.length === 0) return { kind: 'NAME_EMPTY' };
  const taken = players.some((p) => p.id !== editingId && p.name.trim().toLowerCase() === name.toLowerCase());
  return taken ? { kind: 'NAME_TAKEN', name } : null;
}

export function buildPlayer(draft: PlayerDraft, id: string): Player {
  return { id, name: draft.name.trim(), gender: draft.gender, attractedTo: draft.attractedTo };
}
```

```tsx
import { Button } from '../components/Button';
import { Screen } from '../components/Screen';
import { buildPlayer, EMPTY_DRAFT, validatePlayerDraft, type PlayerDraft, type PlayerFormError } from '../logic/playerForm';

interface PlayersProps {
  readonly tonight: readonly string[];
  readonly onTonightChange: (ids: readonly string[]) => void;
  readonly onBack: () => void;
  readonly onContinue: () => void;
}

function errorText(error: PlayerFormError): string {
  return error.kind === 'NAME_EMPTY' ? es.players.errors.nameEmpty : es.players.errors.nameTaken(error.name);
}

export function Players({ tonight, onTonightChange, onBack, onContinue }: PlayersProps) {
  const { state, update } = useUserState();
  const [editing, setEditing] = useState<string | null>(null);
  const [draft, setDraft] = useState<PlayerDraft>(EMPTY_DRAFT);
  const [error, setError] = useState<PlayerFormError | null>(null);

  const resetForm = (): void => {
    setEditing(null);
    setDraft(EMPTY_DRAFT);
    setError(null);
  };

  const startEdit = (player: Player): void => {
    setEditing(player.id);
    setDraft({ name: player.name, gender: player.gender, attractedTo: player.attractedTo });
    setError(null);
  };

  const toggle = (id: string): void => {
    onTonightChange(tonight.includes(id) ? tonight.filter((x) => x !== id) : [...tonight, id]);
  };

  const remove = (player: Player): void => {
    update((current) => ({ ...current, players: current.players.filter((p) => p.id !== player.id) }));
    onTonightChange(tonight.filter((id) => id !== player.id));
    if (editing === player.id) resetForm();
  };

  const submit = (event: FormEvent): void => {
    event.preventDefault();
    const problem = validatePlayerDraft(draft, state.players, editing);
    if (problem !== null) {
      setError(problem);
      return;
    }
    if (editing === null) {
      const player = buildPlayer(draft, crypto.randomUUID());
      const isFirst = state.players.length === 0;
      update((current) => ({ ...current, players: [...current.players, player] }));
      onTonightChange([...tonight, player.id]);

      const id = editing;
      update((current) => ({ ...current, players: current.players.map((p) => (p.id === id ? buildPlayer(draft, id) : p)) }));
    }
    resetForm();
  };

          <li key={player.id} className="list__item glass" data-testid="player-row">

              className="chip"
              aria-pressed={tonight.includes(player.id)}

              data-testid="player-toggle"

              {player.name}

              </Button>
              <Button variant="quiet" aria-label={es.players.remove(player.name)} onClick={() => remove(player)}>
                {es.common.delete}
              </Button>
            </div>
          </li>
        ))}
```

```ts
import { GAME_MODES, type Card, type GameMode, type Level } from '../../core/content/types';
import { missingContent, type GameConfig, type Penalty } from '../../core/game/engine';

export interface SetupDraft {
  readonly modes: readonly GameMode[];
  readonly level: Level;
  readonly penalty: Penalty;
  /** +18 confirmation for this game only; never persisted. */
  readonly adultConfirmed: boolean;
}

export const DEFAULT_DRAFT: SetupDraft = {
  modes: ['TRUTH_OR_DARE'],
  level: 'SOFT',
  penalty: { kind: 'NONE' },
  adultConfirmed: false,
};

export function draftFromLastConfig(last: GameConfig | undefined): SetupDraft {
  return last === undefined ? DEFAULT_DRAFT : { ...last, adultConfirmed: false };
}

export function toggleMode(draft: SetupDraft, mode: GameMode): SetupDraft {
  const selected = draft.modes.includes(mode) ? draft.modes.filter((m) => m !== mode) : [...draft.modes, mode];
  return { ...draft, modes: GAME_MODES.filter((m) => selected.includes(m)) };
}

export function setLevel(draft: SetupDraft, level: Level): SetupDraft {
  return { ...draft, level, adultConfirmed: level === 'EXTREME' ? draft.adultConfirmed : false };
}

export function toConfig(draft: SetupDraft): GameConfig {
  return { modes: draft.modes, level: draft.level, penalty: draft.penalty };
}

export type StartBlocker =
  | { readonly kind: 'NO_MODES' }
  | { readonly kind: 'NOT_ENOUGH_PLAYERS' }
  | { readonly kind: 'ADULT_UNCONFIRMED' }
  | { readonly kind: 'MISSING_CONTENT'; readonly modes: readonly GameMode[] };

export function startBlockers(draft: SetupDraft, cards: readonly Card[], playerCount: number): StartBlocker[] {
  const blockers: StartBlocker[] = [];
  if (draft.modes.length === 0) blockers.push({ kind: 'NO_MODES' });
  if (playerCount < 2) blockers.push({ kind: 'NOT_ENOUGH_PLAYERS' });
  if (draft.level === 'EXTREME' && !draft.adultConfirmed) {
    blockers.push({ kind: 'ADULT_UNCONFIRMED' });
  } else if (draft.modes.length > 0) {
    const missing = missingContent(toConfig(draft), cards);
    if (missing.length > 0) blockers.push({ kind: 'MISSING_CONTENT', modes: missing });
  }
  return blockers;
}
```

```tsx
  const value = useContext(Context);

export function CardsProvider({ children }: { children: ReactNode }) {
  const { state } = useUserState();
  const base = useMemo(() => loadBaseCards(), []);
  const [extreme, setExtreme] = useState<readonly Card[] | null>(null);
  const [loadError, setLoadError] = useState<string | null>(null);
  const extremeRef = useRef<readonly Card[] | null>(null);
  const customRef = useRef(state.customCards);
  customRef.current = state.customCards;

  const getCards = useCallback(
    (): readonly Card[] => [...base, ...(extremeRef.current ?? []), ...customRef.current],
    [base],
  );

  const loadExtreme = useCallback(async (): Promise<boolean> => {
    if (extremeRef.current !== null) return true;
    try {
      const loaded = await loadExtremeCards();
      extremeRef.current = loaded;
      setExtreme(loaded);
      setLoadError(null);
      return true;
    } catch (error) {
      setLoadError(`${es.errors.contentTitle}: ${error instanceof Error ? error.message : String(error)}`);
      return false;
    }
  }, []);

  const cards = useMemo(() => [...base, ...(extreme ?? []), ...state.customCards], [base, extreme, state.customCards]);
  const api = useMemo<CardsApi>(
    () => ({ cards, extremeLoaded: extreme !== null, getCards, loadExtreme, loadError }),
    [cards, extreme, getCards, loadExtreme, loadError],
  );
  return <Context.Provider value={api}>{children}</Context.Provider>;
}
```

```tsx
import { createContext, useCallback, useContext, useEffect, useMemo, useRef, useState, type ReactNode } from 'react';
import { systemClock } from '../core/game/clock';
import { createGame, reduce, type EngineDeps, type GameAction, type GameConfig, type GameState } from '../core/game/engine';
import type { Player } from '../core/game/player';
import { createMathRng } from '../core/game/rng';
import { useCards } from './CardsContext';
import { useUserState } from './UserStateContext';

interface GameApi {
  readonly game: GameState | null;
  /** The last engine error, with its input. Shown to the user; cleared by the next successful action. */
  readonly error: string | null;
  start(config: GameConfig, players: readonly Player[], adultConfirmed: boolean): boolean;
  dispatch(action: GameAction): void;
  discard(): void;
}

const Context = createContext<GameApi | null>(null);

export function useGame(): GameApi {
  const value = useContext(Context);
  if (value === null) throw new Error('useGame must be used inside GameProvider');
  return value;
}

function messageOf(error: unknown): string {
  return error instanceof Error ? error.message : String(error);
}

export function GameProvider({ children }: { children: ReactNode }) {
  const { state, update } = useUserState();
  const { getCards } = useCards();
  const [game, setGame] = useState<GameState | null>(null);
  const [error, setError] = useState<string | null>(null);
  const gameRef = useRef<GameState | null>(null);
  const historyRef = useRef(state.history);
  const savedHistory = useRef<GameState['history'] | null>(null);
  const rng = useMemo(() => createMathRng(), []);

  historyRef.current = state.history;

  // getCards reads refs, so extreme cards loaded a moment ago are already included.
  const deps = useCallback((): EngineDeps => ({ cards: getCards(), rng, clock: systemClock }), [getCards, rng]);

  const publish = useCallback((next: GameState | null): void => {
    gameRef.current = next;
    setGame(next);
  }, []);

  const start = useCallback(
    (config: GameConfig, players: readonly Player[], adultConfirmed: boolean): boolean => {
      try {
        publish(createGame(config, players, historyRef.current, deps(), adultConfirmed));
        setError(null);
        return true;
      } catch (failure) {
        setError(`Could not start with ${JSON.stringify(config)} and ${players.length} players: ${messageOf(failure)}`);
        return false;
      }
    },
    [deps, publish],
  );

  const dispatch = useCallback(
    (action: GameAction): void => {
      const current = gameRef.current;
      if (current === null) throw new Error(`Action ${JSON.stringify(action)} was dispatched without a game in progress`);
      try {
        publish(reduce(current, action, deps()));
        setError(null);
      } catch (failure) {
        setError(`${action.type} failed (${JSON.stringify(action)}): ${messageOf(failure)}`);
      }
    },
    [deps, publish],
  );

  const discard = useCallback((): void => {
    publish(null);
    setError(null);
  }, [publish]);

  // The engine keeps the history; persist it after every card shown (decision 9).
  useEffect(() => {
    if (game === null || game.history === savedHistory.current) return;
    savedHistory.current = game.history;
    update((current) => ({ ...current, history: game.history }));
  }, [game, update]);

  const api = useMemo<GameApi>(
    () => ({ game, error, start, dispatch, discard }),
    [game, error, start, dispatch, discard],
  );
  return <Context.Provider value={api}>{children}</Context.Provider>;
}
```

```tsx
import { useState } from 'react';
import { useCards } from '../../app/CardsContext';
import { useGame } from '../../app/GameContext';
import { useUserState } from '../../app/UserStateContext';
import { GAME_MODES, LEVELS, type Level } from '../../core/content/types';
import { es } from '../../i18n/es';
import { Button } from '../components/Button';
import { Dialog } from '../components/Dialog';
import { Screen } from '../components/Screen';
import {
  draftFromLastConfig,
  setLevel,
  startBlockers,
  toConfig,
  toggleMode,
  type SetupDraft,
  type StartBlocker,
} from '../logic/setupLogic';
import { useLevelBackdrop } from '../theme/useAppearance';

const DRINK_COUNTS = [1, 2, 3, 4, 5] as const;

interface SetupProps {
  readonly tonight: readonly string[];
  readonly onBack: () => void;
  readonly onStarted: () => void;
}

function blockerText(blocker: StartBlocker): string {
  switch (blocker.kind) {
    case 'MISSING_CONTENT':
      return es.setup.blockers.MISSING_CONTENT(blocker.modes.map((mode) => es.setup.modeNames[mode]).join(', '));
    case 'NO_MODES':
      return es.setup.blockers.NO_MODES;
    case 'NOT_ENOUGH_PLAYERS':
      return es.setup.blockers.NOT_ENOUGH_PLAYERS;
    case 'ADULT_UNCONFIRMED':
      return es.setup.blockers.ADULT_UNCONFIRMED;
  }
}

export function Setup({ tonight, onBack, onStarted }: SetupProps) {
  const { state, update } = useUserState();
  const { cards, loadExtreme, loadError } = useCards();
  const { start, error } = useGame();
  const [draft, setDraft] = useState<SetupDraft>(() => draftFromLastConfig(state.settings.lastConfig));
  const [askingAdult, setAskingAdult] = useState(false);
  const [loadingExtreme, setLoadingExtreme] = useState(false);
  useLevelBackdrop(draft.level);

  const players = state.players.filter((player) => tonight.includes(player.id));
  const blockers = startBlockers(draft, cards, players.length);

  const chooseLevel = (level: Level): void => {
    if (level === 'EXTREME' && !draft.adultConfirmed) setAskingAdult(true);
    else setDraft(setLevel(draft, level));
  };

  const confirmAdult = async (): Promise<void> => {
    setLoadingExtreme(true);
    const loaded = await loadExtreme();
    setLoadingExtreme(false);
    setAskingAdult(false);
    if (loaded) setDraft({ ...setLevel(draft, 'EXTREME'), adultConfirmed: true });
  };

  const begin = (): void => {
    const config = toConfig(draft);
    if (!start(config, players, draft.adultConfirmed)) return;
    update((current) => ({ ...current, settings: { ...current.settings, lastConfig: config } }));
    onStarted();
  };

  return (
    <Screen title={es.setup.title} onBack={onBack}>
      <section className="stack stack--tight" aria-label={es.setup.modes}>
        <h2>{es.setup.modes}</h2>
        <div className="row">
          {GAME_MODES.map((mode) => (
            <button
              key={mode}
              type="button"
              className="chip"
              aria-pressed={draft.modes.includes(mode)}
              onClick={() => setDraft(toggleMode(draft, mode))}
              data-testid={`mode-${mode}`}
            >
              {es.setup.modeNames[mode]}
            </button>
          ))}
        </div>
      </section>

      <section className="stack stack--tight" aria-label={es.setup.level}>
        <h2>{es.setup.level}</h2>
        <div className="row">
          {LEVELS.map((level) => (
            <button
              key={level}
              type="button"
              className="chip"
              aria-pressed={draft.level === level}
              onClick={() => chooseLevel(level)}
              data-testid={`level-${level}`}
            >
              {es.setup.levelNames[level]}
            </button>
          ))}
        </div>
        <p className="stage__label">{es.setup.levelHints[draft.level]}</p>
      </section>

      <section className="stack stack--tight" aria-label={es.setup.penalty}>
        <h2>{es.setup.penalty}</h2>
        <div className="row">
          {(['NONE', 'DRINKS', 'GARMENT'] as const).map((kind) => (
            <button
              key={kind}
              type="button"
              className="chip"
              aria-pressed={draft.penalty.kind === kind}
              onClick={() =>
                setDraft({
                  ...draft,
                  penalty: kind === 'DRINKS' ? { kind, count: 2 } : kind === 'GARMENT' ? { kind } : { kind },
                })
              }
              data-testid={`penalty-${kind}`}
            >
              {es.setup.penaltyKinds[kind]}
            </button>
          ))}
        </div>
        {draft.penalty.kind === 'DRINKS' ? (
          <div className="row" role="group" aria-label={es.setup.drinksCount}>
            {DRINK_COUNTS.map((count) => (
              <button
                key={count}
                type="button"
                className="chip"
                aria-pressed={draft.penalty.kind === 'DRINKS' && draft.penalty.count === count}
                onClick={() => setDraft({ ...draft, penalty: { kind: 'DRINKS', count } })}
                data-testid={`drinks-${count}`}
              >
                {es.setup.drinks(count)}
              </button>
            ))}
          </div>
        ) : null}
      </section>

      {blockers.map((blocker) => (
        <p key={blocker.kind} className="banner" role="alert" data-testid="setup-blocker">
          {blockerText(blocker)}
        </p>
      ))}
      {loadError === null ? null : (
        <p className="banner" role="alert">
          {loadError}
        </p>
      )}
      {error === null ? null : (
        <p className="banner" role="alert" data-testid="game-error">
          {error}
        </p>
      )}

              {es.setup.adult.cancel}

          </div>

    </Screen>
  );
}
```

```ts
  if (nowMs < startedAtMs) throw new Error(`Countdown clock went backwards: started at ${startedAtMs}, now ${nowMs}`);
```

```ts
import { useEffect, useState } from 'react';
import { remainingSeconds } from './countdown';

export function useCountdown(totalSeconds: number) {
  const [startedAt, setStartedAt] = useState<number | null>(null);
  const [remaining, setRemaining] = useState(totalSeconds);

  useEffect(() => {
    if (startedAt === null) return;
    const tick = (): void => setRemaining(remainingSeconds(totalSeconds, startedAt, performance.now()));
    tick();
    const id = window.setInterval(tick, 250);
    return () => window.clearInterval(id);
  }, [startedAt, totalSeconds]);

  return {
    remaining,
    running: startedAt !== null && remaining > 0,
    finished: startedAt !== null && remaining === 0,
    start: (): void => setStartedAt(performance.now()),
  };
}
```

```tsx
function nameOf(game: GameState, playerId: string): string {
  const player = game.players.find((p) => p.id === playerId);
  if (player === undefined) {
    throw new Error(`Player ${playerId} is not in the game (players: ${game.players.map((p) => p.id).join(', ')})`);
  }
  return player.name;
}

function ChoiceView({
  game,
  phase,
  onChoose,
  onSkip,
}: {
  game: GameState;
  phase: Extract<Phase, { kind: 'AWAITING_CHOICE' }>;
  onChoose: (choice: Choice) => void;
  onSkip: () => void;
}) {
  const noneAvailable = phase.unavailable.length === 2;
  return (
    <div className="stage">
      <div>
        <p className="stage__label">{es.play.turnOf}</p>
        <h2 className="stage__name" data-testid="turn-name">
          {nameOf(game, phase.playerId)}
        </h2>
      </div>
      {noneAvailable ? (
        <>
          <p className="banner" role="alert">
            {es.play.noCardPossible}
          </p>
          <Button variant="primary" onClick={onSkip} data-testid="choice-skip">
            {es.play.skipTurn}
          </Button>
        </>
      ) : (
        <div className="stage__actions stage__actions--stacked">
          <Button disabled={phase.unavailable.includes('TRUTH')} onClick={() => onChoose('TRUTH')} data-testid="choice-truth">
            {es.play.truth}
          </Button>
          <Button variant="primary" onClick={() => onChoose('RANDOM')} data-testid="choice-random">
            {es.play.random}
          </Button>
          <Button disabled={phase.unavailable.includes('DARE')} onClick={() => onChoose('DARE')} data-testid="choice-dare">
            {es.play.dare}
          </Button>
        </div>
      )}
    </div>
  );
}

function Timer({ seconds }: { seconds: number }) {
  const { remaining, running, finished, start } = useCountdown(seconds);

  useEffect(() => {
    // Support varies by platform (spec open question 4); a missing API simply means no buzz.
    if (finished && 'vibrate' in navigator) navigator.vibrate([200, 100, 200]);
  }, [finished]);

  return (
    <div className="stack stack--tight">
      <p className="timer" role="timer" data-testid="timer">
        {remaining}
      </p>
      {finished ? (
        <p className="stage__label" role="status">
          {es.play.timeUp}
        </p>
      ) : null}
      {running || finished ? null : (
        <Button onClick={start} data-testid="timer-start">
          {es.play.startTimer}
        </Button>
      )}
    </div>
  );
}

function CardView({
  game,
  phase,
  onComplete,
  onRefuse,
  onNext,
}: {
  game: GameState;
  phase: Extract<Phase, { kind: 'SHOWING_CARD' }>;
  onComplete: () => void;
  onRefuse: () => void;
  onNext: () => void;
}) {
  const timerSeconds = phase.card.timerSeconds;
  return (
    <div className="stage">
      {phase.playerId === null ? (
        <p className="stage__label">{es.play.groupHint}</p>
      ) : (
        <div>
          <p className="stage__label">{es.cards.types[phase.card.type]}</p>
          <h2 className="stage__name stage__name--compact">{nameOf(game, phase.playerId)}</h2>
        </div>
      )}
      <Glass thick className="stage__card" data-testid="card-text">
        {phase.text}
      </Glass>
      {timerSeconds === undefined ? null : <Timer seconds={timerSeconds} />}
      {phase.playerId === null ? (
        <Button variant="primary" onClick={onNext} data-testid="card-next">
          {es.play.next}
        </Button>
      ) : (
        <div className="stage__actions">
          <Button variant="primary" onClick={onComplete} data-testid="card-complete">
            {es.play.complete}
          </Button>
          <Button onClick={onRefuse} data-testid="card-refuse">
            {es.play.refuse}
          </Button>
        </div>
      )}
    </div>
  );
}

export function Play() {
  const { game, error, dispatch, discard } = useGame();
  const { loadExtreme } = useCards();
  const { state } = useUserState();
  const [menuOpen, setMenuOpen] = useState(false);
  useLevelBackdrop(game?.config.level ?? 'SOFT');

  useEffect(() => {
    if (game === null) navigate('home');
  }, [game]);

  if (game === null) return null;
  const { phase } = game;
  const leave = (): void => {
    discard();
    navigate('home');
  };

  return (
    <main className="screen" data-testid="play">
      <header className="screen__bar">
        <p className="stage__label">{game.lastMode === null ? null : es.setup.modeNames[game.lastMode]}</p>
        <Button variant="quiet" onClick={() => setMenuOpen(true)} data-testid="play-menu">
          {es.play.menu.open}
        </Button>
      </header>

      {error === null ? null : (
        <p className="banner" role="alert" data-testid="game-error">
          {es.play.errorTitle}: {error}
        </p>
      )}

      {phase.kind === 'AWAITING_CHOICE' ? (
        <ChoiceView
          key={game.round}
          game={game}
          phase={phase}
          onChoose={(choice) => dispatch({ type: 'CHOOSE', choice })}
          onSkip={() => dispatch({ type: 'SKIP_TURN' })}
        />
      ) : null}
      {phase.kind === 'SHOWING_CARD' ? (
        <CardView
          key={game.round}
          game={game}
          phase={phase}
          onComplete={() => dispatch({ type: 'COMPLETE' })}
          onRefuse={() => dispatch({ type: 'REFUSE' })}
          onNext={() => dispatch({ type: 'NEXT' })}
        />
      ) : null}
      {phase.kind === 'SHOWING_PENALTY' ? (
        <div className="stage">
          <div>
            <p className="stage__label">{es.play.refuse}</p>
            <h2 className="stage__name stage__name--compact">{nameOf(game, phase.playerId)}</h2>
          </div>
          <Glass thick className="stage__card" data-testid="penalty-text">
            {describePenalty(phase.penalty)}
          </Glass>
          <Button variant="primary" onClick={() => dispatch({ type: 'NEXT' })} data-testid="penalty-next">
            {es.play.next}
          </Button>
        </div>
      ) : null}
      {phase.kind === 'PAUSED_NEED_PLAYERS' ? (
        <div className="stage">
          <p className="banner" role="status" data-testid="paused">
            {es.play.paused}
          </p>
        </div>
      ) : null}
      {phase.kind === 'ENDED' ? (
        <div className="stage">
          <h2 className="stage__name stage__name--compact">{es.play.ended}</h2>
          <Button variant="primary" onClick={leave} data-testid="ended-home">
            {es.play.backHome}
          </Button>
        </div>
      ) : null}

      {menuOpen ? (
        <PlayMenu
          game={game}
          savedPlayers={state.players}
          dispatch={dispatch}
          loadExtreme={loadExtreme}
          onClose={() => setMenuOpen(false)}
        />
      ) : null}
    </main>
  );
}
```

```ts
import type { Card, CardType, Level } from '../../core/content/types';
import { checkCard } from '../../core/content/validator';

export interface CardDraft {
  readonly type: CardType;
  readonly level: Level;
  readonly text: string;
  /** Raw input value; empty means no timer. */
  readonly timerSeconds: string;
}

export const EMPTY_CARD_DRAFT: CardDraft = { type: 'TRUTH', level: 'SOFT', text: '', timerSeconds: '' };

/** Builds a card through the same validator the packs use. Throws with every problem and the input. */
export function buildCustomCard(draft: CardDraft, id: string): Card {
  const timer = draft.timerSeconds.trim();
  const raw = {
    id,
    type: draft.type,
    level: draft.level,
    text: draft.text.trim(),
    tags: [],
    ...(timer === '' ? {} : { timerSeconds: Number(timer) }),
  };
  const check = checkCard(raw, id);
  if (check.card === null) throw new Error(`${check.problems.join('; ')} (input: ${JSON.stringify(raw)})`);
  return check.card;
}
```

```js
  let c = n;
  for (let k = 0; k < 8; k += 1) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;

  let c = 0xffffffff;

function chunk(type, data) {
  const typeBytes = Buffer.from(type, 'ascii');

  length.writeUInt32BE(data.length);

      raw[offset + 3] = a;
```

```ts
export interface LensSpec {
  /** Size of the element in CSS pixels. */
  readonly width: number;
  readonly height: number;
  /** Corner radius in CSS pixels. */
  readonly radius: number;
  /** Width of the refracting rim in CSS pixels; the interior stays neutral. */
  readonly bezel: number;
}

/** Distance from a point to the edge of a rounded rectangle; positive inside, zero on the edge. */
export function signedInsideDistance(x: number, y: number, spec: LensSpec): number {
  const halfWidth = spec.width / 2;
  const halfHeight = spec.height / 2;
  const qx = Math.abs(x - halfWidth) - (halfWidth - spec.radius);
  const qy = Math.abs(y - halfHeight) - (halfHeight - spec.radius);
  const outside = Math.hypot(Math.max(qx, 0), Math.max(qy, 0)) + Math.min(Math.max(qx, qy), 0) - spec.radius;
  return -outside;
}

/** Unit vector pointing from the edge toward the inside, from a numeric gradient of the distance. */
function inwardDirection(x: number, y: number, spec: LensSpec): readonly [number, number] {
  const step = 0.75;
  const gx = signedInsideDistance(x + step, y, spec) - signedInsideDistance(x - step, y, spec);
  const gy = signedInsideDistance(x, y + step, spec) - signedInsideDistance(x, y - step, spec);
  const length = Math.hypot(gx, gy);
  return length === 0 ? [0, 0] : [gx / length, gy / length];
}

const NEUTRAL = 128;

/**
 * RGBA pixels of a displacement map for feDisplacementMap (R = x, G = y, 128 = no shift).
 * The shift is strongest on the edge and falls to zero at the inner side of the bezel, and it
 * points inward, so the rim shows content bent toward the center like a convex lens.
 */
export function renderDisplacementPixels(spec: LensSpec): Uint8ClampedArray {
  const data = new Uint8ClampedArray(spec.width * spec.height * 4);
  for (let y = 0; y < spec.height; y += 1) {
    for (let x = 0; x < spec.width; x += 1) {
      const px = x + 0.5;
      const py = y + 0.5;
      const depth = signedInsideDistance(px, py, spec) / spec.bezel;
      const strength = depth >= 1 ? 0 : (1 - Math.max(depth, 0)) ** 2;
      const [dx, dy] = inwardDirection(px, py, spec);
      const offset = (y * spec.width + x) * 4;
      data[offset] = Math.round(NEUTRAL + 127 * dx * strength);
      data[offset + 1] = Math.round(NEUTRAL + 127 * dy * strength);
      data[offset + 2] = NEUTRAL;
      data[offset + 3] = 255;
    }
  }
  return data;
}
```

```ts
import { renderDisplacementPixels, type LensSpec } from './displacementMap';

/** Draws the displacement map on a canvas and returns it as a PNG data URI (allowed by img-src data:). */
export function renderDisplacementMapUrl(spec: LensSpec): string {
  const canvas = document.createElement('canvas');
  canvas.width = spec.width;
  canvas.height = spec.height;
  const context = canvas.getContext('2d');
  if (context === null) throw new Error(`Cannot get a 2D canvas context for a ${spec.width}x${spec.height} displacement map`);
  context.putImageData(new ImageData(renderDisplacementPixels(spec), spec.width, spec.height), 0, 0);
  return canvas.toDataURL('image/png');
}
```

```ts
interface NavigatorWithBrands extends Navigator {
  readonly userAgentData?: { readonly brands: readonly { readonly brand: string }[] };
}

/**
 * Only Chromium renders `backdrop-filter: url(#svg-filter)` (Safari and Firefox ignore it, see decision 1).
 * Whether Chrome for Android renders feDisplacementMap inside it is NOT verified: check on the phone (Task 15, step 8).
 */
export function supportsRefraction(): boolean {
  const brands = (navigator as NavigatorWithBrands).userAgentData?.brands;
  const isChromium = brands !== undefined && brands.some((entry) => entry.brand === 'Chromium');
  return isChromium && CSS.supports('backdrop-filter', 'url(#probe)');
```

```tsx
import { useEffect, useId, useMemo, useRef, useState } from 'react';
import { Glass, type GlassProps } from '../components/Glass';
import { renderDisplacementMapUrl } from './renderMap';
import { supportsRefraction } from './supportsRefraction';

const RADIUS = 34; // matches --radius-lg
const BEZEL = 28;
const SCALE = 46; // feDisplacementMap scale in px: how far the rim bends the backdrop

interface Size {
  readonly width: number;
  readonly height: number;
}

/** Glass with an SVG refraction layer on the rim when the browser can render it; plain glass otherwise. */
export function LensGlass({ style, children, ...rest }: GlassProps) {
  const supported = useMemo(() => supportsRefraction(), []);
  const ref = useRef<HTMLDivElement>(null);
  const filterId = `lens-${useId().replace(/[^a-zA-Z0-9]/g, '')}`;
  const [size, setSize] = useState<Size | null>(null);

  useEffect(() => {
    const element = ref.current;
    if (!supported || element === null) return;
    const observer = new ResizeObserver(([entry]) => {
      if (entry === undefined) return;
      const width = Math.round(entry.borderBoxSize[0]?.inlineSize ?? 0);
      const height = Math.round(entry.borderBoxSize[0]?.blockSize ?? 0);
      if (width > 0 && height > 0) setSize((current) => (current?.width === width && current.height === height ? current : { width, height }));
    });
    observer.observe(element);
    return () => observer.disconnect();
  }, [supported]);

  const mapUrl = useMemo(
    () => (supported && size !== null ? renderDisplacementMapUrl({ ...size, radius: RADIUS, bezel: BEZEL }) : null),
    [supported, size],
  );

  return (
    <>
      {mapUrl === null || size === null ? null : (
        <svg width="0" height="0" aria-hidden="true" focusable="false" style={{ position: 'absolute' }}>
          <filter id={filterId} x="0" y="0" width={size.width} height={size.height} filterUnits="userSpaceOnUse" colorInterpolationFilters="sRGB">
            <feImage href={mapUrl} x="0" y="0" width={size.width} height={size.height} result="map" />
            <feDisplacementMap in="SourceGraphic" in2="map" scale={SCALE} xChannelSelector="R" yChannelSelector="G" />
          </filter>
        </svg>
      )}
      <Glass
        ref={ref}
        data-refract={mapUrl === null ? undefined : 'true'}
        style={mapUrl === null ? style : { ...style, backdropFilter: `url(#${filterId}) blur(6px) saturate(1.8)` }}
        {...rest}
      >
        {children}
      </Glass>
    </>
  );
}
```
